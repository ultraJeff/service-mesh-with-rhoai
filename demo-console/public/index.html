1 The Problem 2 min
RHOAI 3.4 provides TLS at the ingress layer and optional auth via enable-auth: true. For most deployments, this is sufficient. For regulated and high-security environments that require mutual authentication, workload identity, and east-west encryption — we harden RHOAI with a service mesh.
What the service mesh adds:
CapabilityRHOAI AloneRHOAI + Mesh
Ingress TLSYesYes (custom CA)
Mutual authenticationNoYes (mTLS)
Workload identityNoYes (SPIFFE)
East-west encryptionNoYes (ztunnel)
Customer-managed CANoYes (cert-manager)
L7 authorization policyNoYes (waypoint)
2 The Solution — Ambient Mesh 3 min
We layer OSSM v3 ambient mesh on top. No application changes — ztunnel transparently intercepts traffic and encrypts it with mTLS. Zero sidecars. Apps serve plain HTTP; the mesh handles encryption.

      Multi-Cluster Preview

        because they chain to the same trust anchor. This is the foundation for

        securely between clusters without per-cluster trust configuration.
